# Chimera — Windows downloads

Installationspaket och uppdateringskanal för Chimera, en Windows-app för separata webbläsarprofiler med Chromium, Brave och uppmätt miljödiagnostik.

**[Hämta senaste versionen](https://github.com/toysrus837273/Chimera-releases/releases/latest)** · Windows 10/11 x64

Kör installationspaketet för att installera eller uppgradera Chimera. Vid uppgradering behålls profilerna. Från version 0.3 kan appen söka efter nya versioner och erbjuda **Hämta → Installera och starta om** eller **Senare**. Version 0.1/0.2 behöver först uppgraderas manuellt. Brave behöver installeras separat om du vill använda Brave-profiler.

Detta är utvecklingsversioner. Paketen är ännu inte kodsignerade; Windows kan visa okänd utgivare. Varje release innehåller SHA256SUMS för manuell kontroll. Uppdateraren verifierar SHA-512 mot releaseinformationen. Fingeravtrycksskyddet bygger på Braves egna funktioner och garanterar inte ett unikt eller odetekterbart fingeravtryck.

Här finns endast publika installationspaket och releaseinformation. Utvecklingsrepo och historik är privata. Appen distribueras under MIT; beroenden har sina respektive licenser, som följer med paketet.
